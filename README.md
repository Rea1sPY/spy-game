# جاسوس | SPY — بازی گروهی فارسی و آفلاین برای اندروید

بازی حضوری با **یک گوشی**: همه به‌جز جاسوس یک کلمه مخفی را می‌دانند؛ با سؤال و جواب جاسوس را پیدا کنید.
رابط فارسی و راست‌چین، تم تیره (مشکی/بنفش/آبی)، بدون نیاز به اینترنت و بدون ساخت حساب.

- ۴۹ دسته‌بندی + گزینه «ترکیب تصادفی» · **۱۵۲۱ کلمه و عبارت**، بدون تکرار
- ۳ تا ۲۰ بازیکن، تعداد جاسوس قابل تنظیم، ۱ تا ۱۰ دور، زمان ۱/۲/۳/۵/۱۰ دقیقه
- نمایش مخفی نقش‌ها، زمان‌سنج با توقف/ادامه، رأی‌گیری مخفی، رأی‌گیری مجدد در صورت تساوی
- حدس کلمه توسط جاسوس (متن آزاد یا ۱۲ گزینه پیشنهادی، با نرمال‌سازی فارسی)
- امتیازدهی قابل تنظیم، جدول امتیازات، آمار و رکوردها (ذخیره محلی)

## فناوری
فقط **یک فناوری** برای بازی: HTML + CSS + JavaScript (داخل `app/src/main/assets`).
پوسته اندروید یک `WebView` ساده با Kotlin است (کمتر از ۱۲۰ خط) که فایل‌های داخل برنامه را باز می‌کند.

## دریافت APK — روش ۱: GitHub Actions (بدون نصب هیچ‌چیز)
1. در github.com یک مخزن جدید بسازید (مثلاً `spy-game`).
2. **محتوای** پوشه `SpyGame` را در ریشه مخزن آپلود کنید (پوشه `.github` هم باید باشد؛ فایل‌های مخفی را از قلم نیندازید).
   با گیت: `git init && git add . && git commit -m init && git branch -M main && git remote add origin <آدرس> && git push -u origin main`
3. به تب **Actions** بروید. workflow به نام **Build APK** خودکار اجرا می‌شود (یا Run workflow را بزنید).
4. پس از سبز شدن، وارد همان اجرا شوید و پایین صفحه در بخش **Artifacts** فایل **`spy-game-apk`** را دانلود کنید.
5. ZIP دانلودی را باز کنید؛ **مسیر APK:** `app-debug.apk`
   (مسیر داخل Runner: `app/build/outputs/apk/debug/app-debug.apk`)

## دریافت APK — روش ۲: Android Studio
1. Android Studio (نسخه Koala یا جدیدتر) و JDK 17 را نصب کنید.
2. **File ▸ Open** و پوشه `SpyGame` را انتخاب کنید و صبر کنید Gradle همگام شود (نیاز به اینترنت برای بار اول).
3. **Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)**
4. خروجی: `app/build/outputs/apk/debug/app-debug.apk`

با خط فرمان (اگر Gradle 8.7+ و Android SDK نصب دارید): `gradle assembleDebug`

## نصب روی گوشی
1. فایل `app-debug.apk` را به گوشی منتقل کنید (کابل، بلوتوث، تلگرام، …).
2. روی فایل بزنید. اگر اندروید پرسید، اجازه **نصب از این منبع** را به برنامه‌ای که فایل را باز کرده بدهید.
3. نصب را تأیید کنید و برنامه «جاسوس» را اجرا کنید. (حداقل اندروید ۸٫۰)

> APK ساخته‌شده با کلید debug امضا می‌شود؛ برای نصب شخصی کافی است. برای انتشار در فروشگاه‌ها باید کلید اختصاصی بسازید.

## امنیت اطلاعات مخفی
- کلمه و نقش‌ها فقط در حافظه همان دور هستند؛ هرگز در `localStorage`، آمار، پیام خطا یا لاگ نوشته نمی‌شوند.
- روی صفحه‌های نقش/رأی/حدس، اندروید با `FLAG_SECURE` اسکرین‌شات و پیش‌نمایش برنامه‌های اخیر را مسدود می‌کند.
- نقش با دکمه «متوجه شدم» (یا رفتن برنامه به پس‌زمینه، یا دکمه بازگشت) از صفحه پاک می‌شود؛ هیچ تاریخچه‌ای برای برگشت وجود ندارد.
- قفل کوتاه بعد از «متوجه شدم» جلوی لمس دوباره و دیدن اتفاقی نقش نفر بعد را می‌گیرد.
- بازی هیچ اعلان (Notification) و هیچ مجوز اینترنتی ندارد.

## قوانین پیش‌فرض
- رأی‌گیری یک نفر را انتخاب می‌کند. اگر جاسوس باشد و «حدس کلمه» فعال باشد، فرصت حدس دارد (درست: جاسوس برنده؛ غلط: عادی‌ها). اگر جاسوس نباشد: جاسوس برنده.
- آرا مساوی: یک بار رأی‌گیری مجدد بین افراد مساوی؛ باز هم مساوی → جاسوس برنده (یا طبق تنظیم: فوراً جاسوس برنده).
- پایان زمان: رفتن به رأی‌گیری (یا طبق تنظیم: جاسوس برنده).
- امتیازها (تنظیمات ◂ امتیازها): عادی‌ها ۲، جاسوس فراری ۳، حدس درست ۴، پاداش رأی درست ۱. مقدار پیش‌فرض در `js/config.js` است.
- در بازی چندجاسوسی، رأی‌گیری یک نفر را انتخاب می‌کند؛ جاسوس‌ها یکدیگر را نمی‌شناسند و همه با هم امتیاز می‌گیرند.

## افزودن دسته و کلمه
فایل `app/src/main/assets/js/words.js`:
- **کلمه جدید:** آن را به انتهای رشته همان دسته اضافه کنید، با «،» جدا کنید.
- **دسته جدید:** یک خط `C('شناسه-انگلیسی-یکتا', 'نام فارسی', '🙂', \`کلمه۱، کلمه۲، ...\`),` به آرایه اضافه کنید.
  دسته در صفحه انتخاب دسته‌ها خودکار ظاهر می‌شود.
- بعد از ویرایش `node tests/run-logic-tests.js` را اجرا کنید: تکراری بودن، حروف عربی (ي/ك) و حداقل ۱۲ کلمه برای هر دسته بررسی می‌شود.

## اجرای تست‌ها
```
node tests/run-logic-tests.js          # منطق بازی، بدون وابستگی
pip install playwright && playwright install chromium
python3 tests/ui-test.py               # یک بازی کامل در مرورگر
```
برای دیدن بازی در مرورگر کامپیوتر/گوشی، `app/src/main/assets/index.html` را مستقیم باز کنید.
